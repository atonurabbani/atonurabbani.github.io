HOW TO PUBLISH ON GITHUB PAGES
1. Create a public repository named yourusername.github.io
2. Upload every file in this folder (not the Archive folder) to it
3. Settings > Pages > Deploy from a branch > main, / (root)
4. Visit https://yourusername.github.io after a minute or two

TO FINISH THE SITE
- Add photo.jpg (square, about 400px), then in index.html replace the <div class="photo">...</div> contents with <img src="photo.jpg" alt="Atonu Rabbani">
- Replace the "#" links for Google Scholar / ORCID / RePEc in research.html
- Fill the yellow "Media and talks" note in projects.html (or delete it)
- cv.pdf is your CV with the home address and phone number removed
- To update: edit the .html files (plain text) and re-upload
